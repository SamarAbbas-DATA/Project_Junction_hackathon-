# UI references and attribution

The interface uses Motion for React (https://motion.dev), MIT licensed; see its installed package license.

The controlled shared-highlight interaction in `apps/web/src/components/ui/motion.tsx` is adapted from the interaction pattern in Watermelon UI Tabs, with application-specific markup, styling, keyboard behavior and reduced-motion support. The rest of the dashboard composition and graphics are implemented for this project using the user's supplied visual reference.

Reference: https://github.com/WatermelonCorp/watermellon-registry/blob/main/src/components/watermelon-ui/tabs.tsx
